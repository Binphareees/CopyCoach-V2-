# CopyCoach AI Database Specification

Version:
1.0 MVP


# Database Overview

Database technology:

PostgreSQL (Supabase)


The database stores:

- User accounts
- User profiles
- Copywriting exercises
- User drafts
- AI evaluations
- Progress tracking
- Achievements


---

# 1. Users Table

## Purpose

Stores account information.


Table Name:

users


Fields:


id

Type:
UUID

Description:
Unique user identifier.


---

email

Type:
Text

Description:
User email address.


---

password

Type:
Managed by Supabase Auth


Description:
Secure authentication.


---

created_at

Type:
Timestamp

Description:
Account creation date.


---

# Security Rules


Users can:

- View their own profile
- Create their own drafts
- View their own reviews
- Update their own progress


Users cannot:

- Access another user's private data
